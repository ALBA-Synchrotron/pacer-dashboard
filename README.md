# PACER dashboard

The PACER Dashboard is an optional monitoring component for PACER. When deployed, it provides real-time visibility into
message processing activities across the platform. Its primary purpose is to offer a user-friendly interface that
enables participating teams to monitor data ingestion workflows, trace message processing, and efficiently diagnose and
troubleshoot errors.
